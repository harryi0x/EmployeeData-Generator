# Employee Data Generator

A simple Employee Data Generator built using Node.js, Express.js, MongoDB, and Mongoose.

## Features

* Generate 10 random employee records.
* Store employee data in MongoDB.
* Delete previous records before generating new data.
* Display employee records in an HTML table.
* Generate fresh data on every button click.

## Technologies

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose

## Installation

1. Clone this repository.
2. Run `npm install`.
3. Make sure MongoDB is running locally.
4. Run `node main.js`.
5. Open `http://localhost:3000`.

## Database

Database: `company`

Collection: `employees`

Each employee contains name, salary, language, city, and isManager.
